# test_code/welder — 오프라인 검증

`test_weld.py` — 용접 시퀀스 + 3겹 검증 10항목.

## 무엇을 확인했나

**핵심 질문: "덮어서 안 보이니까 수리됨"이 되어버리지 않는가.**

관벽 Depth 를 세 가지로 합성해 넣고 각 겹이 실제로 작동하는지 봤다.

| 시나리오 | 정렬 | 프로파일 | 검출기 | 결과 |
|---|---|---|---|---|
| 정상 수리 | OK | 메워짐 | 미검출 | **SUCCESS** |
| 정렬 빗나감 + 파임 | 초과 | 파임 | 검출 | FAILED |
| **파여 있는데 검출기가 놓침** | OK | **파임 +1.16mm** | 미검출 | **FAILED** ← ②가 뒤집음 |
| 메워졌는데 오검출 | OK | 메워짐 | 검출 | FAILED |
| 정렬만 초과 | 초과 | 메워짐 | 미검출 | FAILED |
| 용접 전 미검출 | — | — | — | FAILED (대상 아님) |
| 1차 실패 → 재시도 | | | | SUCCESS |

세 번째 줄이 ②를 넣은 이유다. 검출기 하나였으면 성공으로 기록됐을 경우다.

## 겪은 것 — 분위수를 쓰면 안 된다

처음에 프로파일 판정을 창 전체의 **99분위**로 했더니 **2.2mm 파인 크랙이
+0.00mm 로 나왔다.**

크랙은 폭 1.6mm 라 화면에서 3화소 남짓이다. 80×80 창의 99분위는 상위 64화소인데
크랙 화소가 그보다 적어 완전히 묻혔다.

중앙값 필터(3×3)로 단발 잡음만 걷어내고 **최댓값**을 쓰되, 이어진 면적이
`min_deep_px` 이상일 때만 결함으로 본다. 한 화소 튐으로 오판하지 않으면서
좁은 크랙은 살린다.
