# welder — 용접 모듈

수리기 전용. 토치 2자유도 + 용접 시퀀스 + **3겹 검증**.

## 왜 3겹인가

**"덮어서 안 보이니까 수리됨"이 되면 안 된다.**

비드는 화면을 가리는 게 아니라 형상을 바꾼다 — 벽 + 비드 = 메워진 표면이라
RGB·Depth 둘 다 일관되게 메워짐을 본다. 설계가 색상 덮어쓰기를 배제한 이유가
그것이다(Depth 는 여전히 홈을 읽어 "안 보이는데 파여 있는" 모순이 생긴다).

그래도 **"검출기가 못 찾음 = 수리 성공"** 이라는 판정 기준 자체는 약하다.
조명·각도 때문에 놓쳐도 성공으로 기록된다. 세 겹으로 막는다.

| 겹 | 내용 | 막는 것 | 출처 |
|---|---|---|---|
| ① 정렬 오차 | 토치가 결함 위치에 안 맞으면 결함 프림 **유지** | 무조건 성공 (자기충족) | 설계 7.2 |
| ② Depth 프로파일 | 홈이 실제로 메워졌는지 **깊이로** 확인 | 검출기 거짓 음성 | **추가** |
| ③ 검출기 반전 | 용접 전 검출 → 용접 후 미검출 | 애초에 대상이 아닌 것 | 설계 7.1 |

②가 필요한 이유가 하나 더 있다. 실패 시나리오는 "결함 유지 + 비드를 어긋난
위치에 표시"인데, 그 비드가 카메라 시선에서 결함 앞을 가리면 **실패인데
미검출**이 되어 우연히 성공으로 기록된다. Depth 프로파일은 그것도 잡는다.

세 겹은 AND 다. 프로파일이 "여전히 파임"이면 검출기가 못 찾아도 실패다.

## 결함·비드 — 불리언 없이

설계 12.5 는 구멍을 "불리언 컷"으로 만든다고 적었으나 **Isaac Sim 에는
불리언 연산이 없다.** 테셀레이션 단계에서 셀을 빼고 옆벽을 세워 만든다.

결함 조각과 비드 조각은 **같은 개구부에 끼우는 한 쌍**이다. 가시성만 전환하면
형상이 실제로 바뀐다.

| 메시 | 실측 |
|---|---|
| `defect_crack` | 관벽에서 **+2.20mm 파임** |
| `bead_crack` | 관 안쪽으로 **0.80mm 돌출** |
| `defect_hole` | 관통 (면 없음) |
| `bead_hole` | 관 안쪽으로 **0.80mm 돌출**, 부피차 243mm³ |

## 토치 — 본체를 감싸는 회전 링

**바퀴는 전진·후진만 되고 조향이 없다.** 관절도 수동이라 로봇을 결함 방향으로
돌릴 수단이 없다. 대신 **본체를 감싸는 링이 돌아** 토치를 원주 방향 어디로든
겨눈다.

| 관절 | 사양 | 근거 |
|---|---|---|
| J1 회전 (링) | **±180°** | 360° 연속은 슬립링 필요, **슬립링은 용접 전류에 부적합** |
| J2 직동 | 스트로크 8mm (반경 40 → 48mm) | 링이 이미 r=30 까지 실어 나른다 |

**회전축을 관 중심축과 일치**시키면 어느 방향으로 돌려도 토치·관벽 간극이
일정하다. 관절식(회전 2개)은 직선 팔 끝점이 원통 벽면을 따라가지 않는다.
용접봉은 회전축 중심의 중공으로 공급해 ±180° 에서도 안 꼬인다.

설계의 J2 스트로크 35mm 는 토치를 축 근처(r=20)에 달았을 때 값이다. 링 방식은
출발점이 r=30 이라 8mm 면 된다.

### 배치 (실측 검증)

```
링          x +58 ~ +68   내경 26 / 외경 30
가장 앞선 암 x     +54     ← 여유 4.0mm
카메라       x +68.9 ~ +79.1
```

| 항목 | 값 |
|---|---|
| 수납 시 최대 반경 | **40.0mm** — 곡관에서 본체·암이 41.7mm 까지 가므로 그보다 안쪽 |
| 최대 신장 반경 | **48.0mm** — 관벽까지 용접 간극 2mm |
| 암·휠 축방향 여유 | 4.0mm (스태거를 10 → 7mm 로 줄여 확보) |

스태거를 줄이자 **곡관 필요 스트로크도 ±4.59 → ±4.02mm 로 함께 감소**했다.
휠 접촉점이 덜 퍼지기 때문이다.

링크 3개(`torch_ring` / `torch_rod` / `torch_tip`)로 나눠 낸다. articulation 을
걸어야 하기 때문이다.

## 🚨 용접 지점은 제자리에서 안 보인다

화각 140° 라도 관벽(r=50)이 시야에 들어오려면 **전방 18.2mm 이상** 떨어져야
한다. 용접 지점은 로봇 바로 옆 관벽이라 입사각이 90° 를 넘는다.

**링을 앞에 두든 뒤에 두든 같다.** 전방을 보는 카메라는 원리적으로 "옆의 벽"을
볼 수 없다. 그래서 시퀀스에 **REPOSITION** 이 들어간다.

| 방식 | 같은 화질(입사각 24°)까지 이동 |
|---|---|
| **전방 카메라 + 후진 120mm** | 채택 — 그 자리에서 성패 확정 |
| 후방 카메라 + 전진 246mm | 실패를 알았을 때 이미 지나침 |

후방 카메라는 **복귀 감사**(`audit.py`)에 쓴다.

## 시퀀스

```
APPROACH → RECHECK → ALIGN → ARC → COOL → REPOSITION → VERIFY → SUCCESS
                ↓                                          ↓
             FAILED                                  RETRY(1회) → APPROACH
          (용접 전 미검출)                                  ↓
                                                        FAILED
```

냉각은 결함 크기에 비례(기본 5s + 0.8s/mm)한다.

## 파일

| 파일 | 역할 |
|---|---|
| `weld.py` | 시퀀스 FSM + 3겹 검증 (ROS 비의존) |
| `audit.py` | 복귀 감사 — 후방 카메라로 전 구간 재대조 (③번 겹) |
| `articulate.py` | 수리기 17링크 articulation (**Isaac Sim**) |
| `meshes/torch_*.stl` | 링 / 로드 / 팁 |
| `config/weld.yaml` | 임계값 |

결함·비드 메시는 `pipe/meshes/` 에 있다(배관에 속한 것이라).
